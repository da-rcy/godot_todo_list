# godot_todo_list
A simple todo list for Godot 4.5.1

This is a free plugin I made for fun and to use in my own project. Feel free to edit and use however you like.
You can double click on any list item to change the text, you can also right click to mark complete which will cross it out. You can press mark complete again to un-cross it out.

From the right click menu you can also delete any item.
Keep this docked wherever you like, it will generally remember where you last docked it and any todo item does save when you close godot.

To Install:
Simply unzip everything into a "todo_list" folder and move this folder into your Godot addon folder:
res://addons/todo_list
